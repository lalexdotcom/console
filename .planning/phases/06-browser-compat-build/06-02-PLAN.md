  ### Step 1 — Run the build

  ```bash
  pnpm run build
  ```

  Expected outcome: exits with code 0. Zero warnings in stderr.
  If the build fails, read the error output carefully:
  - `Cannot resolve 'node:*'` → a node: import was missed in Plan 06-01; fix the source file.
  - TypeScript error → read the exact error and fix the relevant file.
  - Rslib config error → re-read rslib.config.ts for syntax issues.

  Do NOT proceed to the verification steps until the build exits with code 0.

  ---

  ### Step 2 — Validate dist/ structure against exports map

  The updated exports map declares these paths:

  | Condition | Path |
  |-----------|------|
  | `.` types | `./dist/index.d.ts` |
  | `.` browser | `./dist/browser/index.js` |
  | `.` import | `./dist/index.js` |
  | `./worker` types | `./dist/worker/index.d.ts` |
  | `./worker` import | `./dist/worker/index.js` |

  Run the existence check:
  ```bash
  ls -la dist/index.js dist/index.d.ts dist/browser/index.js dist/worker/index.js dist/worker/index.d.ts
  ```

  All five files must be present. If any is missing:
  - `dist/browser/index.js` missing → lib[3] in rslib.config.ts was not saved correctly; re-read and fix.
  - Other files missing → underlying rslib issue; check build output for errors.

  ---

  ### Step 3 — Verify browser bundle purity (BROWSER-03)

  ```bash
  grep -E "node:child_process|node:path|node:url" dist/browser/index.js
  ```

  Expected: **no output** (exit code 1). These Node-only specifiers must not appear in the
  browser output.

  Also verify the main bundle (belt-and-suspenders — these were never in main's dep tree):
  ```bash
  grep -E "node:child_process|node:path|node:url" dist/index.js
  ```
  Expected: no output.

  If `grep` returns matches in `dist/browser/index.js`:
  - The node: import is coming from a transitive dependency of `src/index.ts`.
  - Run `grep -rn "from 'node:" src/` to find the offending file.
  - Fix it following the same pattern as env.ts / renderer.ts (remove import, use conditional access).

  ---

  ### Step 4 — TypeScript type check

  ```bash
  pnpm exec tsc --noEmit
  ```

  Expected: exits with code 0, zero errors printed.

  If there are errors, read each one carefully. Common causes after this phase:
  - `processEnv` typing changed (env.ts) — ensure the cast `{} as Record<string, string | undefined>` is correct.
  - `stripVTControlCharacters` not found (renderer.ts) — ensure the function was added before `getLineCount`.
  </action>
