**CRITICAL: Module mock placement (D-04)**

The `rs.mock()` call MUST appear before all imports because rstest hoists it to run before module evaluation. This is the only file in the codebase that uses `rs.hoisted` + `rs.mock` — follow the pattern precisely.

**File structure:**
```typescript
import { rs } from '@rstest/core';

// D-04: Force isNodeTTY=true BEFORE any module evaluates.
// rstest hoists rs.mock() transforms to run before static imports are resolved.
// This ensures selectSpinnerFactory() sees isTTY=true at module load time.
rs.mock('../../../src/utils/env', async () => {
  const actual = await rs.importActual<typeof import('../../../src/utils/env')>(
    '../../../src/utils/env'
  );
  return { ...actual, isNodeTTY: true };
});

// Imports come AFTER the mock declaration (hoisting handles evaluation order)
```
