**CORE-07 describe block** — Verify that browser output uses `%c` CSS format strings.

The assertion pattern (D-08): `logSpy.mock.calls[0][0]` (or `debugSpy.mock.calls[0][0]`) must contain `'%c'`.

Setup (inside describe, not at file level):
```typescript
let logSpy: ReturnType<typeof rs.spyOn>;
let debugSpy: ReturnType<typeof rs.spyOn>;
beforeEach(() => {
  logSpy = rs.spyOn(console, 'log').mockImplementation(() => {});
  debugSpy = rs.spyOn(console, 'debug').mockImplementation(() => {});
});
afterEach(() => { logSpy.mockRestore(); debugSpy.mockRestore(); });
```

Key tests:
1. `'info level: first arg of console.log contains %c (CSS format string)'` —
   `L.info('test')`. Assert `logSpy.mock.calls.length >= 1` and
   `(logSpy.mock.calls[0][0] as string).includes('%c')`.

2. `'debug level: first arg of console.debug contains %c'` —
   `L.debug('test')`. Assert `debugSpy.mock.calls.length >= 1` and
   `(debugSpy.mock.calls[0][0] as string).includes('%c')`.

3. `'notice level: first arg of console.log contains %c'` —
   `L.notice('test')`. Assert `logSpy.mock.calls[0][0]` includes `'%c'`.

4. `'all non-TRACE non-debug levels emit %c-prefixed output'` — Use `test.each` for
   `['success', 'notice', 'info']` levels (non-TRACE, non-debug). For each, call `L[level]('test')`,
   then assert `logSpy.mock.calls.length >= 1 && (logSpy.mock.calls[0][0] as string).includes('%c')`.

**CORE-08 describe block** — Verify that TRACE_LEVELS calls use `console.groupCollapsed` and `console.groupEnd`.

Setup (inside describe):
```typescript
let groupCollapsedSpy: ReturnType<typeof rs.spyOn>;

  groupCollapsedSpy = rs.spyOn(console, 'groupCollapsed').mockImplementation(() => {});
  groupEndSpy = rs.spyOn(console, 'groupEnd').mockImplementation(() => {});
  // spy on console.error to verify it is NOT called directly
  errorSpy = rs.spyOn(console, 'error').mockImplementation(() => {});
});
afterEach(() => { groupCollapsedSpy.mockRestore(); groupEndSpy.mockRestore(); errorSpy.mockRestore(); });
```

Key tests:
1. `'error level uses groupCollapsed and groupEnd (not direct console.error)'` —
   `L.error('oops')`.
   ```typescript
   expect(groupCollapsedSpy.mock.calls.length).toBeGreaterThanOrEqual(1);
   expect(groupEndSpy.mock.calls.length).toBeGreaterThanOrEqual(1);
   // TRACE_LEVELS path does NOT call console.error directly:
   expect(errorSpy.mock.calls.length).toBe(0);
   ```

2. `'groupCollapsed first arg also contains %c CSS format string'` —
   `L.error('oops')`. Assert
   `(groupCollapsedSpy.mock.calls[0][0] as string).includes('%c')`.

3. `'warn level uses groupCollapsed and groupEnd'` — Same as test 1 with `L.warn('warning')`.

4. `'all TRACE_LEVELS emit groupCollapsed + groupEnd sequence'` — Use `test.each` for
   `['emerg', 'alert', 'crit', 'error', 'warn']`. For each, assert
   `groupCollapsedSpy.mock.calls.length >= 1` and `groupEndSpy.mock.calls.length >= 1`.
   Add `beforeEach(() => { groupCollapsedSpy.mockClear(); groupEndSpy.mockClear(); })` inside this inner describe.

5. `'non-TRACE level (info) does NOT use groupCollapsed'` —

Setup for spy (inside describe, refreshed per test):

The browser spinner uses `createSequentialSpinner` (same timer loop as console spinner). Each tick fires `dispatch → emitConsole` browser path → `console.log` with `%c`-prefixed format string containing the icon badge CSS.

**Test patterns:**

1. `'browser spinner start emits an immediate %c-prefixed console.log call'` —
   ```typescript
   L.scope('spin-09-start').info.spin('loading');
   // createSequentialSpinner calls render('running') synchronously on start()
   expect(logSpy.mock.calls.length).toBeGreaterThanOrEqual(1);
   expect((logSpy.mock.calls[0][0] as string).includes('%c')).toBe(true);
   ```

2. `'browser spinner tick emits %c-prefixed console.log call after timer advance'` —
   ```typescript
   L.scope('spin-09-tick').info.spin('tick test'); // start call captured by logSpy
   logSpy.mockClear(); // discard start call
   rs.advanceTimersByTime(BROWSER_TICK_ADVANCE);
   expect(logSpy.mock.calls.length).toBeGreaterThanOrEqual(1);
   expect((logSpy.mock.calls[0][0] as string).includes('%c')).toBe(true);
   ```

3. `'browser spinner success call emits %c-prefixed console.log call'` —
   ```typescript
   const sp = L.scope('spin-09-success').info.spin('task');
   logSpy.mockClear(); // discard start call
   sp.success('done');
   expect(logSpy.mock.calls.length).toBeGreaterThanOrEqual(1);
   expect((logSpy.mock.calls[0][0] as string).includes('%c')).toBe(true);
   ```

4. `'browser spinner with progress: true emits %c CSS gradient output on tick'` —
   ```typescript
   const sp = L.scope('spin-09-prog').info.spin('load', { progress: true });
   sp.update('loading', { progress: 0.5 });
   logSpy.mockClear();
   rs.advanceTimersByTime(BROWSER_TICK_ADVANCE);
   // Progress renders CSS gradient bar — still routed through console.log with %c format
   expect(logSpy.mock.calls.length).toBeGreaterThanOrEqual(1);
   expect((logSpy.mock.calls[0][0] as string).includes('%c')).toBe(true);
   ```
