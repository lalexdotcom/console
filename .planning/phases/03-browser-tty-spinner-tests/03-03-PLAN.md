   Find call with `method === 'debug'`. Assert `call.args[0]` contains `'%c'`.

**SPIN-09 describe block** — Verify browser spinner emits %c CSS-styled icon badges.

Use `beforeAll(() => rs.useFakeTimers())` / `afterAll(() => rs.useRealTimers())` (D-01).

The browser spinner uses `createSequentialSpinner` (same timer loop as console spinner). Each tick fires `dispatch → emitConsole` browser path → `console.log` with `%c`-prefixed format string containing the icon badge CSS.

**Test patterns:**

1. `'browser spinner start emits an immediate %c-prefixed console.log call'` —
   ```typescript
   const calls = spyOnConsole(() => {
     L.scope('spin-09-start').info.spin('loading');
   });
   // createSequentialSpinner calls render('running') synchronously on start()
   const logCalls = calls.filter(c => c.method === 'log' || c.method === 'debug');
   expect(logCalls.length).toBeGreaterThanOrEqual(1);
   expect(typeof logCalls[0].args[0]).toBe('string');
   expect((logCalls[0].args[0] as string).includes('%c')).toBe(true);
   ```

2. `'browser spinner tick emits %c-prefixed console.log call'` —
   ```typescript
   // Start spinner, then advance fake timers inside spyOnConsole to capture tick output
   let sp!: ReturnType<ReturnType<typeof L.scope>['info']['spin']>;
   spyOnConsole(() => {
     sp = L.scope('spin-09-tick').info.spin('tick test');
   }); // discard start calls

   const tickCalls = spyOnConsole(() => {
     rs.advanceTimersByTime(BROWSER_TICK_ADVANCE);
   });
   const logTickCalls = tickCalls.filter(c => c.method === 'log' || c.method === 'debug');
   expect(logTickCalls.length).toBeGreaterThanOrEqual(1);
   expect((logTickCalls[0].args[0] as string).includes('%c')).toBe(true);
   ```

3. `'browser spinner success call emits %c-prefixed console.log call'` —
   ```typescript
   const startCalls = spyOnConsole(() => {
     sp = L.scope('spin-09-success').info.spin('task');
   });
   const successCalls = spyOnConsole(() => {
     sp.success('done');
   });
   const logCalls = successCalls.filter(c => c.method === 'log');
   expect(logCalls.length).toBeGreaterThanOrEqual(1);
   expect((logCalls[0].args[0] as string).includes('%c')).toBe(true);
   ```

4. `'browser spinner with progress: true emits %c CSS gradient output'` —
   ```typescript
   const sp = (() => {
     let ref!: ReturnType<ReturnType<typeof L.scope>['info']['spin']>;
     spyOnConsole(() => { ref = L.scope('spin-09-prog').info.spin('load', { progress: true }); });
     return ref;
   })();
   sp.update('loading', { progress: 0.5 });
   const calls = spyOnConsole(() => {
     rs.advanceTimersByTime(BROWSER_TICK_ADVANCE);
   });
   // Progress renders CSS gradient bar — still routed through console.log with %c format
   const logCalls = calls.filter(c => c.method === 'log');
   expect(logCalls.length).toBeGreaterThanOrEqual(1);
   expect((logCalls[0].args[0] as string).includes('%c')).toBe(true);
   ```

**Note on IIFE pattern above:** If TypeScript complains about the IIFE, use a simpler let/beforeEach pattern to declare the spinner reference. The key constraint is that spyOnConsole captures are separate — start is captured separately so success/tick captures are clean.
