<objective>
Remove all top-level `node:` imports from files in the main entry's dependency tree, add a
dedicated browser lib entry to rslib.config.ts, and expose a `"browser"` exports condition
in package.json.

Purpose: Without these changes a browser bundler (Webpack/Rspack/Vite in browser mode) will
fail to resolve `node:process` and `node:util` at build time, even though the runtime guards
prevent those code paths from executing. Source fixes + a separate browser output entry are the
correct library pattern (per Decision 5: no polyfill plugins).

Output:
- `src/utils/env.ts` — conditional `process.env` access, no import
- `src/logger/mixins/spinner/tty/renderer.ts` — inline `stripVTControlCharacters`, no import
- `rslib.config.ts` — lib[3] entry → `dist/browser/index.js`
- `package.json` — `"browser"` condition added to the `.` exports entry
</objective>

  ### src/utils/env.ts

  Replace the top-level `node:process` import with a runtime-safe inline const.
  The `import type { inspect }` line is a type-only import — bundlers strip it; leave it intact.

  **Search (exact, including surrounding lines for uniqueness):**
  ```typescript
  import { env as processEnv } from 'node:process';
  import type { inspect } from 'node:util';
  ```

  **Replace with:**
  ```typescript
  import type { inspect } from 'node:util';

  // Runtime-safe access to process.env — works in both Node.js and browser contexts.
  const processEnv = typeof process !== 'undefined' ? (process.env ?? {}) : {} as Record<string, string | undefined>;
  ```

  No other changes in this file. The `processEnv` variable is used in three places that
  all remain correct: `export const env`, `isNodeTTY`, and nothing else.

  ```typescript
  function stripVTControlCharacters(text: string): string {

    return text.replace(/\x1b(?:[@-Z\\-_]|\[[0-9;]*[ -/]*[@-~])/g, '');
  }

  /** Returns the number of terminal lines a rendered string occupies. */
  function getLineCount(text: string): number {
  ```

  The rest of `getLineCount` and all other functions in the file are unchanged.
